What the number can’t account for

Awarded as a set
Bandai hands this card out only inside its card set, one set per qualifying player, so every card in the set has the same population as the set.
Card list reconstructed from the physical cards
Bandai's Finals Season 1 page lists the set only as "CS 25-26 Winner Card Set 1 × 6" without naming the six cards or showing images. The six cards here were identified from the printed cards themselves (each carries the CHAMPIONSHIP 25-26 Champion stamp); the images are scans of the actual cards rather than Bandai's official sample images.
