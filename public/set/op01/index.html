OP-01 Romance Dawn

OP-01 (Romance Dawn) on Log Pose is every prize card, promo and chase pull tracked for that booster, 52 cards in all. It is not a checklist of the whole set. Release date on file: December 2, 2022. 28 of them have a documented print-run population, the lowest being Tony Tony.Chopper OP01-015 (Champion) at 7+. 24 are unpublished, because the printing is confirmed and no print run was published. The tiers on this page are Champion (8), SP Card (6), 1st Anniversary Set (EN) (5), and China 1st ANNIVERSARY SET (5). Each card links to the page with the event-by-event working and the official sources.
